# 3-minute demo video script

Judges stop at 3:00, so the walkthrough comes early. Record the screen at 1080p with the browser zoomed to 125%. Record a backup take.

| Time | Screen | Voice-over |
|---|---|---|
| 0:00-0:20 | Title card, then a photo or sketch of a multigrade room | "In most Indian government primary schools, one teacher teaches two or three grades in one room. While she teaches Class 1, Class 2 sits with a copying task. Doosri Awaaz is a second voice for that grade: guided practice in the children's home language, then Hindi, with no internet in class." |
| 0:20-0:50 | Prepare page: paste the lesson, press Draft. Cut to the Review page | "Before class, the teacher pastes this week's lesson. Claude drafts a 15-minute oral activity pack in Marathi and Hindi. A second Claude call scores it against a rubric and flags phrases a native speaker should check. Code checks every item has one right answer." |
| 0:50-1:10 | Review page: edit one Marathi line, type name, Approve | "A teacher or local speaker edits anything that sounds wrong and approves. Only approved lines are voiced, and only approved packs can run." |
| 1:10-2:10 | Turn Wi-Fi off on camera (offline badge turns dark). Classroom simulator: Start; question plays in Marathi then Hindi; children answer aloud ("पाच"); one wrong answer gets a hint; press a colour button; a child asks a question that is answered, then one that goes to the teacher | "In class, nothing is online. Speech recognition runs on the device and listens only for that question's answers. If it isn't sure, it asks again; it never marks a child wrong on a mishearing. Children who stay quiet can press a colour. When a child asks something, a small model on the device matches it to answers the teacher approved. If it isn't covered, the device says: ask your teacher." |
| 2:10-2:30 | Debrief plays; then Tomorrow's note on the phone mock-up with the green check | "After the session the teacher hears a 20-second summary: four of five right, counting back was hard. When her phone has network, Claude writes tomorrow's note, and code checks every number in it against the log." |
| 2:30-2:50 | Slide: testing results (teacher quote, one change made) | "We walked a teacher of Class [N] through the app. [Teacher quote]. Based on that we changed [change]." |
| 2:50-3:00 | Slide: repo link, roadmap line | "It runs on the Suno Sutra device or any laptop. Code and evaluations are open source." |

Fill the [brackets] after the teacher call. If the microphone demo is unreliable on the day, show button answers and play one pre-recorded voice answer.
