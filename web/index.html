A second voice for the grade the teacher is not teaching

In a multigrade class, while the teacher works with one grade, a small offline device runs 15-20 minutes of guided oral practice for the other, home language first and then Hindi. Claude prepares the activities before class; a person approves every one; the classroom loop makes no network calls.

1

Prepare online

Claude turns the week's lesson into an activity pack and a second Claude call scores it. A teacher or local speaker edits and approves it.

2

Run in class offline

The device plays the pack to the group. Children answer aloud or with colour buttons. Questions outside the pack go to the teacher.

3

Report optional sync

A 20-second spoken summary for the teacher right away; later, Claude writes a next-day note from the group-level log.
